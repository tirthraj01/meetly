# 📅 Meetly

A modern, full-stack, timezone-aware scheduling platform built with Next.js 14, TypeScript, Prisma, and PostgreSQL. Inspired by Calendly.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Database**: PostgreSQL (Neon Serverless)
- **ORM**: Prisma
- **Auth**: NextAuth.js v5 (Google OAuth)
- **Integrations**: Google Calendar API, Resend
